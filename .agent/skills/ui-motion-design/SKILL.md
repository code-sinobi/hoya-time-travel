# UI Motion Design Skill

This skill ensures consistent, tasteful motion and typography.

## When to use this skill

- Adding animations
- Using Lottie files
- Styling text

## Animation rules

- Subtle by default
- Prefer implicit animations
- Avoid animating layout size aggressively

## Typography

- Use GoogleFonts consistently
- Define text styles in theme
- Avoid inline font styling

## Lottie

- Store in assets by feature
- Keep animations lightweight
